## 2. 已实现

### 2.1 认证与账号

- `POST /api/auth/login`：BCrypt 校验，失败统一提示「账号或密码错误」。
- 连续失败 5 次锁定 15 分钟（进程内计数，重启清零）。
- JWT 载荷含 `userId`、`role`、`tokenVersion`；停用或改密后旧令牌失效。
- `GET /api/auth/me`、`PUT /api/auth/password`、`POST /api/auth/logout`。
- 启动时若不存在账号，初始化：
  - 管理员 `admin` / `Admin@123`（强制改密）
  - 普通用户 `user` / `User@123`
- 首次登录会被前端拦截到改密页。

### 2.2 设备台账

- 新建设备状态固定 `IN_STOCK`。
- 资产编号唯一；序列号填写时唯一。
- 管理员可编辑（不可手改状态和领用冗余字段）、受限删除（仅在库且无领用单）。
- 列表支持类型、状态、关键字、部门、地点筛选；`OVERDUE` 按「已领用且预计归还日早于今天」过滤。
- 普通用户只看到在库设备及本人相关设备，响应不含购置价格、供应商。
- 普通用户打开他人领用中的设备返回 404。

### 2.3 领用状态机

单据与设备在同一事务中更新，乐观锁冲突返回 409，文案为「状态已变化，请刷新」。

| 动作 | 单据 | 设备 |
| --- | --- | --- |
| 提交申请 | `PENDING` | `PENDING` |
| 通过 | `APPROVED` | 仍为 `PENDING` |
| 驳回（原因必填） | `REJECTED` | `IN_STOCK` |
| 撤回 | `WITHDRAWN` | `IN_STOCK` |
| 发放 | `BORROWING` | `BORROWED`，写入领用人与日期 |
| 申请归还 | `RETURN_PENDING` | 仍为 `BORROWED` |
| 归还确认 / 代归还 | `RETURNED` | `IN_STOCK`，清空领用字段 |
| 归还后再申请 | 可再次提交 | 重新变为 `PENDING` |

另支持草稿（不占用设备）、管理员待办三列表、领用履历时间线。预计归还日必须晚于今天且不超过 90 天。

### 2.4 前端页面

已从占位页改为接真实接口：

- 登录、修改密码（含强制改密）
- 设备列表 / 新建 / 编辑 / 详情
- 申请领用（草稿 + 提交确认）
- 我的领用（申请中 / 使用中 / 已完成）

菜单按角色写死：管理员见台账、办理、我的领用；普通用户见设备、我的领用。

## 4. 本机如何验证

依赖：JDK 17、Maven、Node.js 22.18+、本机 MySQL 8（库名 `ams`，账号见 `backend/src/main/resources/application-dev.yml`）。

1. 启动 MySQL，确认库 `ams` 可连接。
2. 在 `backend/` 使用 JDK 17 启动：`mvn spring-boot:run`。首次启动会从仓库根目录 `sql/` 执行 Flyway 建表并打印初始账号。
3. 在 `frontend/` 执行 `npm run dev`，浏览器打开 Vite 地址。
4. 管理员登录后先改密，再新建设备；用 `user` 申请；管理员通过并发放；用户申请归还；管理员确认后设备回到在库。

当前开发机默认 `JAVA_HOME` 是 11，编译阶段 1 后端需要显式使用 `C:\Program Files\Java\jdk-17`。
