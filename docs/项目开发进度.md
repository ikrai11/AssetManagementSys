## 2. 已实现

### 2.1 认证与账号

- `POST /api/auth/login`：BCrypt 校验，失败统一提示「账号或密码错误」。
- 连续失败 5 次锁定 15 分钟（进程内计数，重启清零）。
- JWT 载荷含 `userId`、`role`、`tokenVersion`；停用或改密后旧令牌失效。
- `GET /api/auth/me`、`PUT /api/auth/password`、`POST /api/auth/logout`。
- 启动时若不存在账号，初始化：
  - 管理员 `admin` / `Admin@123`（强制改密）
  - 普通用户 `user` / `User@123`
- 首次登录会被前端拦截到改密页。
- 登录失败与锁定提示显示在登录卡片内；连续失败 5 次后提示「账号已锁定，请 N 分钟后再试」。
- 管理员用户管理：创建账号、分配 `ADMIN` / `USER`、停用/启用、重置密码。
- 普通用户邮箱必填且格式合法；账号唯一；新建和重置后下次登录必须改密。
- 不能停用自己；不能让启用中的管理员数量变为 0（含把最后一名管理员改成普通用户）。
- 停用和重置密码会增加 `token_version`，旧令牌立即失效；停用后登录统一提示「账号或密码错误」。

### 2.2 设备台账

- 新建设备状态固定 `IN_STOCK`。
- 资产编号唯一；序列号填写时唯一。
- 管理员可编辑（不可手改状态和领用冗余字段）、受限删除（仅在库且无领用单）。
- 列表支持类型、状态、关键字、部门、地点筛选；`OVERDUE` 按「已领用且预计归还日早于今天」过滤。
- 普通用户只看到在库设备及本人相关设备，响应不含购置价格、供应商。
- 普通用户打开他人领用中的设备返回 404。

### 2.3 领用状态机

单据与设备在同一事务中更新，乐观锁冲突返回 409，文案为「状态已变化，请刷新」。

| 动作 | 单据 | 设备 |
| --- | --- | --- |
| 提交申请 | `PENDING` | `PENDING` |
| 通过 | `APPROVED` | 仍为 `PENDING` |
| 驳回（原因必填） | `REJECTED` | `IN_STOCK` |
| 撤回 | `WITHDRAWN` | `IN_STOCK` |
| 发放 | `BORROWING` | `BORROWED`，写入领用人与日期 |
| 申请归还 | `RETURN_PENDING` | 仍为 `BORROWED` |
| 归还确认 / 代归还 | `RETURNED` | `IN_STOCK`，清空领用字段 |
| 归还后再申请 | 可再次提交 | 重新变为 `PENDING` |

另支持草稿（不占用设备）、管理员待办三列表、领用履历时间线。预计归还日必须晚于今天且不超过 90 天。领用单号在进程内串行取号后写入，避免两人同时申请时撞号。

16. 管理员新建设备、改名称后保存、再删除。审计日志按该资产编号能看到新增、修改、删除。修改摘要里能看出名称从什么改成什么。
17. 普通用户打开「个人中心」，修改姓名和邮箱后保存。顶栏姓名跟着变。清空邮箱时页面提示不能为空。审计日志按账号能看到「邮箱已更新」，摘要里没有邮箱地址。
